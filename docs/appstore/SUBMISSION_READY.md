## (b) Owner steps, in order

You can do all of these in Safari on the iPhone: appstoreconnect.apple.com, developer.apple.com and github.com. Use
**aA › Request Desktop Website** if a menu is hidden.

1. **Agreements.** Business: Paid Apps Agreement, Tax and Banking all show **Active** (B11–B12).
2. **Users and Access.** Remove anyone who should not have access. Then go to Sandbox › Test Accounts › **+**: use a
   never-used email, region **United States**. Make two accounts (B19).
3. **Existing products.** Monetization › Subscriptions: write down every existing product ID and its status before you
   create anything (B13). IDs can never be reused.
4. **Create the subscription** (B14, B15):
   - Group **DateWise Premium**, display name `DateWise Premium` (EN and ES).
   - Product: reference name `DateWise Premium Monthly`, ID `datewise_premium_monthly`, **1 month**, **USD 19.99** (owner decision, 2026-11-23), no
     introductory offer, Family Sharing off.
   - Localizations: EN `DateWise Premium Monthly` / `Chat and voice coaching with all four AI coaches.` ES
     `DateWise Premium Mensual` / `Coaching por chat y voz con los cuatro coaches con IA.`
   - Review notes: as in [metadata.md §5](metadata.md#5-in-app-purchase-subscription-metadata).
   - **Billing Grace Period: Off.** The review screenshot comes in step 11.
5. **API key and 4 GitHub secrets** for cloud signing: [IPHONE_E2E_DEMO.md §2.1](../qa/IPHONE_E2E_DEMO.md) a–c. The
   key needs **Admin** access. The secrets are `APPLE_TEAM_ID`, `APP_STORE_CONNECT_API_KEY_ID`,
   `APP_STORE_CONNECT_ISSUER_ID` and `APP_STORE_CONNECT_API_KEY_P8`. Delete the `.p8` file afterwards.
6. **Legal pages live** (B22). Approve the v2 Privacy Policy and Terms. Publish `web/privacy.html`, `privacy-es.html`,
   `terms.html`, `terms-es.html` and the rewrite rules in `web/.htaccess` to the `datewiseai.com` host. Then open
   `https://datewiseai.com/privacy-policy` and `/terms-of-service` in Safari: both must show "Last updated: November
   23, 2026". The repository's GitHub Pages workflow **cannot** serve these URLs ([metadata.md §1](metadata.md)).
   Confirm that mail sent to support@datewiseai.com arrives.
7. **Backend.** `main` is protected and already holds v2 (#43). First, the `SANDBOX_NEURON_BUDGET = "6000"` change for
   the review window (A4; at 1,000 App Review gets about 7 replies a day) goes into `main` in a PR that passes the
   required checks. Then deploy chat-v7 from `main`: Actions › **Deploy coach Worker**, target `chat-v7-cost-guard`,
   dry run first, then `dry_run` off, and approve in `production-worker`
   ([WORKER_DEPLOY_RUNBOOK.md](../launch/WORKER_DEPLOY_RUNBOOK.md) §2–5). **Timing:** production now has
   `LEGACY_CLIENTS = "0"` and `REQUIRE_SUBSCRIPTION = "1"`, so this deploy cuts App Store 1.0.2 off (426/403 instead of
   chat). 1.0.2 already gets 502, but deploy close to submission. After approval, set the budget back to 1,000.
8. **Build.** Actions › iOS build › Run workflow from `main`. Tick `signed_build` and `upload_testflight`. Set
   `coach_backend` = **production** and `signing` = **cloud**. Leave `avatar_audio_path` unticked. The run summary
   must **not** say STAGING or AUDIO-PATH. If you already uploaded a 50000+ staging build of 2.0.0, read
   [IPHONE_E2E_DEMO.md §2.3](../qa/IPHONE_E2E_DEMO.md) first.
9. **TestFlight test** on the iPhone: install the build, finish onboarding and the 18+ gate, buy with the Sandbox
   account, then test chat in EN and ES, voice, Restore and Delete my data. Run Sandbox plan P1, R1, N1, E1, F1 and B1
   ([STOREKIT_SANDBOX_TEST_PLAN.md](../qa/STOREKIT_SANDBOX_TEST_PLAN.md)). Any FAIL blocks submission. Test on an iPad
   too, if you have one.
10. **Portrait record** (C2): add your approval date, generation dates and the account used to
    [ASSET_PROVENANCE.md](../legal/ASSET_PROVENANCE.md). Its status line still says "pending"; Apple can ask for it.
11. **Subscription review screenshot:** take a screenshot of the paywall in the TestFlight build, showing the real
    price, and upload it on the product page from step 4.
12. **App Information** (EN, then ES):
    - Name `DateWise AI` (optional; the current name is fine). Subtitle `Your AI dating coach` /
      `Tu coach de citas con IA`. Category **Lifestyle**.
    - Privacy Policy URL `https://datewiseai.com/privacy-policy`.
    - **Content Rights:** "Does your app contain, show, or access third-party content?" Answer **Yes**, then "I have
      the necessary rights". The AI replies come from Meta Llama on Cloudflare; the fonts use the OFL licence; the
      portraits are owner-generated.
    - **Age Rating:** answer as in [metadata.md §2](metadata.md#2-age-rating-questionnaire-app-store-connect--app-information--age-rating).
      The target is **18+**. Use the override if the questionnaire gives a lower rating.
13. **App Privacy.** Answer "Data collection": **Yes**. Then tick exactly these 3 types. For each one, answer
    Purpose = **App Functionality**, Linked to the user = **No**, Used for tracking = **No**:
    - User Content › **Other User Content**
    - Purchases › **Purchase History**
    - Usage Data › **Product Interaction**

    Leave every other type unticked (no Diagnostics, Identifiers, Audio or Location). The reasoning is in
    [metadata.md §3](metadata.md#3-app-privacy-nutrition-label).
14. **Version 2.0.0 page:**
    - Paste the promo text, description, keywords and What's New from [metadata.md](metadata.md), EN and ES.
    - Support URL `https://datewiseai.com/terms-of-service`. Leave the Marketing URL blank.
    - Screenshots (final): upload `docs/appstore/screenshots/<en|es>/6.9/` and `.../ipad-13/` (01 to 05, in order) for each language.
    - App Review Information: sign-in **not required**, plus your name, phone and email. Paste the notes block in
      [metadata.md §4](metadata.md#4-app-review-information) (AI provider, 18+ gate, Sandbox path, fair use, Find a
      table, encryption).

15. **Build and IAP:** select the step 8 build (a number below 5000). Under In-App Purchases and Subscriptions, add
    `datewise_premium_monthly`. Choose **Manually release** and turn on the 7-day phased release. Export compliance
    is already answered by `Info.plist`; if Apple asks anyway, choose "None of the algorithms mentioned above"
    (exempt).
16. **Submit for Review.** After approval: release it, make one real purchase, then set `SANDBOX_NEURON_BUDGET` back
    to 1,000.
